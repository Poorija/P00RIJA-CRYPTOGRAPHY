# p00rija-cryptography

[🇬🇧 English](#english) | [🇮🇷 فارسی](#فارسی)

---

## English

Quick installer for **P00RIJA Cryptography** — an offline-first encryption
suite and end-to-end encrypted messenger.

```bash
npx p00rija-cryptography@latest
```

Downloads the native installer for your platform (macOS, Windows, Linux) from
the project's GitHub releases.

```bash
npx p00rija-cryptography@latest --pwa
```

Serves the web payload locally and opens it in your browser — no install, no
server, everything stays on your machine.

* Node ≥ 18 · zero dependencies · no telemetry

## فارسی

نصب‌کنندهٔ سریع **P00RIJA Cryptography** — مجموعهٔ رمزنگاری آفلاین‌محور و
پیام‌رسان رمزنگاری سرتاسری.

```bash
npx p00rija-cryptography@latest
```

نصب‌کنندهٔ مخصوص سیستم شما (مک، ویندوز، لینوکس) را از نسخه‌های گیت‌هاب دانلود
می‌کند.

```bash
npx p00rija-cryptography@latest --pwa
```

نسخهٔ وب را محلی سرو می‌کند و در مرورگر باز می‌کند — بدون نصب و بدون سرور؛
همه‌چیز روی دستگاه خودتان می‌ماند.

* Node ≥ 18 · بدون وابستگی · بدون تلمتری
